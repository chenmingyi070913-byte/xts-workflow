# 方法

## 这个文件夹放什么
当前在用的产品工作流系统：`协议.md`、`ISO3.md`、`agents/`（岗位说明）、`skills/`。旧版压缩包放 Releases。

## 文件命名
文件名写「内容_版本_日期」，例如 `用户故事清单_V8_1120.md`。日期用北京时间的月日四位数。

## 元数据
每份文件开头写这几行：
```
版本：V8（周中修改写 V8.2、V8.3）
日期：2026-11-20（北京时间）
轮次：V8
流程版本：product-workflow@0.4.0
run_id：（对应工作流库 轮次/V8/runs/ 下的编号）
状态：草稿 / 在用 / 已替代
负责人：（可选）
```
